## 二、功能模块详细设计

### 13. ▲ 设备属性对接与状态联动

**功能描述**：支持对接工程虚拟仿真平台设备，通过改变设备属性值，驱动 3D 组件状态可视化变化。

**交互逻辑**：

- 在右侧属性面板「动态数据配置」中选择「工程虚拟仿真平台」作为数据源
- 输入设备 ID 后，实时接收仿真平台推送的属性值（如：开关状态、运行模式、故障代码）
- 组件状态随属性值实时更新：
  - 设备运行状态：`running` → 模型显示绿色呼吸灯动画
  - 设备停止状态：`stopped` → 模型显示灰色静态
  - 设备故障状态：`fault` → 模型显示红色闪烁 + 语音报警

**UI 元素**：

- 数据源下拉框：`[工程虚拟仿真平台 ▼]`
- 属性映射表：支持配置 `属性字段 → 模型状态` 的映射关系
- 实时属性面板：显示当前设备所有属性值（只读）

### 14. ★ 动态/静态数据配置与云平台对接

**功能描述**：模型支持静态数据（预设值）和动态数据（实时数据）配置，动态数据支持对接行业云平台设备数据。

**数据结构**：
javascript
// 静态数据配置
{
type: 'static',
values: {
temperature: 25,
humidity: 60,
status: 'normal'
}
}

// 动态数据配置
{
type: 'dynamic',
source: 'cloud\_platform', // 或 'simulation\_platform'
endpoint: '/api/device/data',
deviceId: 'device\_001',
mapping: {
// 云平台字段 → 模型属性
cloud\_temp: 'temperature',
cloud\_humidity: 'humidity'
},
refreshInterval: 5000
}

**UI 设计**：

- 数据类型切换：`[静态] [动态]` 单选按钮（默认静态）
- 静态数据：直接输入 JSON 或表单填写各字段值
- 动态数据：
  - 数据源选择：`[行业云平台 ▼] [工程仿真平台 ▼]`
  - 设备列表：下拉选择或手动输入设备 ID
  - 字段映射：可视化拖拽匹配云端字段与模型属性
  - 连接状态指示：绿色圆点（已连接）/ 红色圆点（断开）
  - 测速按钮：测试数据延迟

### 15. ▲ 模型属性配置（标签/按钮/锚点/语音）

**功能描述**：支持对模型进行丰富的交互与展示配置。

#### 15.1 显示标签配置

- **标签内容**：自定义文本（支持变量，如 `${temperature}℃`）
- **显示位置**：模型上方 / 下方 / 左侧 / 右侧 / 自定义坐标偏移
- **样式配置**：字体大小、颜色、边框、背景透明度、是否发光
- **显示条件**：始终显示 / 鼠标悬停显示 / 数据异常时显示

#### 15.2 跳转按钮配置

- **按钮文本**：自定义
- **跳转目标**：内部页面路由 / 外部 URL / 锚点位置
- **打开方式**：新标签页 / 内嵌 iframe / 模态框
- **按钮样式**：图标 + 文字 / 仅图标 / 仅文字，悬浮效果

#### 15.3 导航锚点配置

- **锚点名称**：用于标识
- **视角参数**：目标相机位置（X, Y, Z）、目标看向点（LookAt）
- **过渡动画**：平滑移动 / 瞬间跳转 / 轨道环绕

#### 15.4 语音配置

- **上传语音**：支持 `.mp3`, `.wav` 格式，显示文件大小与时长
- **触发方式**：
  - 点击模型时播放
  - 数据达到阈值时自动播报（如温度 > 30℃ 播报"温度过高"）
  - 定时循环播放（如每 30 秒播报当前状态）
- **音量控制**：0-100% 调节
- **试听功能**：即时播放测试

### 16. ▲ 仿真平台数据实时展示

**功能描述**：支持对接工程虚拟仿真平台，实时展示仿真设备数据，并映射到 3D 模型状态。

**实现方案**：

- **WebSocket 实时推送**：与仿真平台建立长连接，接收设备状态变更
- **数据过滤**：支持按设备类型、区域、优先级过滤展示的数据
- **可视化映射**：
  - 数值型数据：映射为模型颜色渐变（如温度越高越红）
  - 状态型数据：映射为模型动画（开关、旋转、闪烁）
  - 布尔型数据：映射为模型显隐或材质变化

**UI 表现**：

- 在 3D 模型旁显示「实时数据悬浮窗」
- 数据更新时有轻微闪烁或高亮提示
- 支持开启/关闭数据面板显示
- 数据异常时（如超出阈值）自动触发语音报警和模型红色闪烁

**配置路径**：
右侧属性面板 → 数据配置 → 选择「工程虚拟仿真平台」→ 绑定设备 → 配置字段映射

## 三、关键交互流程

### 流程图：设备状态联动

text
\[工程虚拟仿真平台]
│
▼ (WebSocket 推送数据)
\[3D 设计器 - 动态数据监听器]
│
├── 解析设备属性值
│
▼
\[属性映射引擎]
│
├── 状态值 → 模型材质/颜色/动画
│
├── 数值 → 模型尺寸/标签内容
│
└── 报警码 → 语音播放 + 模型闪烁
│
▼
\[3D 场景实时渲染]

### 操作流程：语音配置

1. 选中 3D 模型 → 右侧属性面板
2. 展开「交互与展示配置」→ 勾选「语音配置」
3. 点击「选择文件」上传 `.mp3` 语音文件
4. 设置触发条件（如：点击模型时）
5. 点击「试听」确认效果
6. 点击「应用标签配置」生效

## 四、视觉与交互细节

| 元素        | 设计规范                | 交互说明                  |
| --------- | ------------------- | --------------------- |
| **模型选中态** | 外发光白边 + 半透明高亮框      | 点击模型时激活，属性面板同步显示该模型配置 |
| **数据源状态** | 绿色圆点（正常）/ 红色圆点（异常）  | 鼠标悬停显示延迟时间与最后更新时间     |
| **属性标签**  | 跟随模型，半透明黑色背景 + 绿色文字 | 支持点击穿透，点击模型本身触发跳转/语音  |
| **语音上传**  | 拖拽区域 + 点击上传，显示进度条   | 支持格式校验，错误时红框提示        |
| **实时数据**  | 悬浮面板，带轻微背景模糊        | 数据更新时 200ms 淡入刷新动画    |

javascript
