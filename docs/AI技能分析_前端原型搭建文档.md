# AI 技能分析系统前端原型搭建需求文档 (优化版 V1.1)

> **定位**：面向 AI 代码生成器的前端原型工程指令，请基于本文档生成一个完整的 AI 技能分析系统前端原型。  
> **建议技术栈**：React 18 + TypeScript + Ant Design 5 + ECharts (图表) + D3.js (技能图谱) + React Router 6 + Zustand (状态管理)。  
> **数据策略**：全部采用 Mock 数据，存储在 `src/mock/` 下，前端独立运行，无需后端。

---

## 一、项目概述

### 1.1 背景与目标
构建 AI 技能分析系统，通过可视化数据分析与智能交互，支撑教育智能化与个性化学习。核心目标：
- 可配置的 AI 学伴智能体
- 学习行为多维统计与图表展示
- 技能分析（分类筛选、等级区分、多形态图谱）
- 校内/班级/平台三级排名
- AI 智能进阶推荐（课程 + 技能点）
- 学习参与度多维度分析

## 三、功能模块详细需求

### 3.1 AI 学伴配置模块 (`AICcompanion`)

#### 3.1.1 配置入口
- 页面路由 `/companion`，也可在顶部导航“AI学伴”中跳转。
- 页面中部展示当前配置预览卡片，点击“配置AI学伴”按钮打开模态框。

#### 3.1.2 配置模态框 (Modal)
- 标题：“配置AI学伴”，左侧齿轮图标。
- 表单字段：
  - **学伴昵称**：输入框，最大长度20字符，显示字数计数。
  - **学伴头像**：横向滚动选择器，展示50个头像（用 Mock 头像 URL 数组），点击选中，选中项显示蓝色边框。
  - **角色设定**：下拉选择（学习导师、技能顾问、实验助手等）。
  - **性格设定**：下拉选择（严谨型、亲和型、激励型等）。
  - **自定义设定提示词**：TextArea，多行输入，可描述学伴行为偏好。
- 操作按钮：
  - 【保存配置】：蓝色主按钮，底部居中。点击后保存至全局状态并关闭弹窗，页面预览更新。
  - 【取消】：右上角关闭按钮或底部取消按钮。
- 弹窗样式：半透明遮罩，白色内容区，圆角阴影。

### 3.2 学习行为统计模块 (Dashboard 部分)

#### 3.2.1 统计卡片
横向排列4个卡片，数据从 Mock 获取：
- 回答总数（图标：对话气泡）
- 今日提问（图标：时钟）
- 互动次数（图标：握手）
- 伴学时长（图标：进度条）
- 卡片点击可跳转至详细统计（原型可暂不实现）

#### 3.2.2 数据筛选区
位于图表上方，包含：
- 学校（下拉，如“新大陆大学”）
- 班级（下拉，如“软件工程2班”）
- 学生（下拉/搜索，如“学生1101”）
- 课程（下拉，如“Hadoop基础与应用”）
- 选择后触发 Mock 数据更新，下方图表重渲染。

#### 3.2.3 行为数据图表
- 默认展示柱状图，支持切换为折线图、表格（ECharts 切换）。
- 数据维度：用户登录平台次数。
- 时间粒度切换：年/月/周（下拉按钮组）。
- 时间范围选择：起始日期 ~ 结束日期（DatePicker）。
- 图表 X 轴：年份（2016-2026），Y 轴：次数。
- 操作按钮：【导出明细】（模拟下载 CSV）、【导出总览】、【柱状图】【折线图】【表格】（视图切换按钮组）。

### 3.3 技能分析与图谱模块 (`SkillAnalysis`)

#### 3.3.1 左侧技能分类导航
- 一级分类：A 存储架构、B 计算框架、C 资源调度、D 数仓工具、E 协调服务、F 集群运维。
- 每个分类前有 Checkbox，支持勾选/取消。
- 顶部提供“全选”和“清空”按钮。
- 勾选后，右侧图谱/技能点分布仅展示对应分类的数据。

#### 3.3.2 技能点分布图谱（网格方块）
- 标题：“全量技能点分布（连续视图）”。
- 使用 Grid 渲染技能点方块（如 A001、B002...），每个方块根据得分着色：
  - 绿色（优秀，≥90）
  - 蓝色（良好，60-89）
  - 灰色（待提升，<60）
- 鼠标悬停 Tooltip 显示技能名称与得分。

#### 3.3.3 技能掌握度饼图
- 展示优秀、良好、待提升三部分占比，饼图图例在右侧。
- 使用 ECharts 饼图，颜色与方块一致。

#### 3.3.4 各分类掌握情况柱状图
- X 轴：A-F 分类，Y 轴：技能点数量。
- 每个分类柱子分三段堆叠（绿/蓝/灰），悬停显示数值。

#### 3.3.5 多形态技能图谱（图4）
- 视图切换按钮组：【树状视图】(默认)、【网状视图】、【环形视图】。
- **树状视图**：
  - 使用 D3.js 树形图，根节点“技能根分类”，一级节点为分类字母，二级节点为技能点。
  - 节点可折叠/展开，支持拖拽缩放（可选）。
- **网状视图**：
  - 使用力导向图，节点同树状，连线表示关联。
- **环形视图**：
  - 使用旭日图或径向树，中心为根，向外为分类→技能点。
- 图谱右上角提供导出图片按钮。

### 3.4 排名与推荐模块 (Dashboard 右侧 / 独立区域)

#### 3.4.1 排名卡片
- 横向三张卡片：班级排名 TOP5、校内排名 TOP5、平台排名 TOP5。
- 卡片样式：浅蓝渐变背景，顶部奖杯图标，列表显示头像+姓名+分数（如“陈大为 98%”），排名序号角标。
- 数据 Mock，可随机生成。

#### 3.4.2 AI 智能进阶推荐
- 区域标题：“AI智能进阶推荐”，带机器人图标。
- **推荐课程**：Grid 卡片列表，每张卡片包含：
  - 课程封面（Mock 图片，如统一占位图）
  - 课程名称（如“工业互联网关键技术”）
  - 难度标签（基础、通用、物联网）
  - 评分（火焰图标 + 分数，如 ★91）
- **推荐技能点**：标签云形式，点击跳转技能分析页（原型可仅 UI 展示）。

### 3.5 学习参与度分析模块 (`EngagementAnalysis`)

#### 3.5.1 左侧分类导航
- 树形结构：
  - 学习过程行为数据
    - 学习行为数据（默认选中）
    - 软件实验过程数据
    - 硬件实验过程数据
    - 学习过程操作数据
- 点击切换右侧对应的分析图表。

#### 3.5.2 参与度图表
- 每个维度下展示对应的图表（柱状图/折线图/雷达图），使用 ECharts 实现。
- 维度包括：平台行为、软件实验过程、硬件实验过程、硬件操作、软件操作。
- 筛选区与行为统计模块类似（时间范围、学校、班级、学生），数据联动。

## 四、全局样式与交互规范

- **主色调**：蓝色系（#007BFF 主按钮，深色 #0056b3），绿色（#52c41a 优秀），灰色（#d9d9d9 待提升）。
- **字体**：系统默认无衬线，标题加粗，内容常规。
- **响应式**：主要适配 PC 1920×1080，图表区域可自适应宽度。
- **交互细节**：
  - 所有图表 Tooltip 显示详细信息。
  - 弹窗支持 ESC 关闭、点击遮罩关闭。
  - 按钮有 Hover 颜色过渡、Loading 状态（保存时）。
  - 筛选条件变化时图表显示加载效果再刷新。
