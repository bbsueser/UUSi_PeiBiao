# 人工智能算法训练平台：页面串联与视觉统一设计

日期：2026-09-22  
状态：已确认，待实施计划

## 1. 背景

当前项目是由多份需求文档生成的静态多页面教学实验平台原型，覆盖学生、教师、管理员以及工程仿真、行业云、2D/3D 设计、嵌入式、Jupyter、区块链、AI 分析和硬件智能体等模块。

现有页面内部演示功能较丰富，但页面之间的入口、返回路径、角色状态和品牌视觉不统一。多个专业实验页面没有业务入口，部分导航指向不存在的文件，同时不同页面混用了多套品牌名称、Logo、Emoji 图标和设计系统。

## 2. 目标

在不删除、不重写现有业务功能和 Mock 交互的前提下：

1. 串联登录、工作台、课程、考试、实验及专业工具页面。
2. 为所有正式业务页面提供明确的进入路径和返回路径。
3. 统一品牌名称为“人工智能算法训练平台”。
4. 保留蓝青色调，建立克制、专业的教育科研与工程软件视觉语言。
5. 使用统一线性 SVG 图标替换导航和品牌区域中的 Emoji。
6. 保留当前工作区已有修改，并通过局部合并完成改造。

## 3. 非目标

- 不将项目重写为 Vue、React 或其他 SPA。
- 不引入后端接口、身份认证或真实数据持久化。
- 不重写专业实验工作台内部功能。
- 不为需求中尚未实现的模块新增完整业务页面。
- 不把 `color-preview.html` 和 `navigation-template.html` 纳入正式产品导航。

## 5. 技术方案

采用渐进式统一壳层，不改变现有静态多页面结构。

### 5.1 共享主题

新增 `css/platform-theme.css`，集中定义：

- 品牌色、背景色、边框色和文本色。
- 品牌栏、侧边栏、面包屑和返回按钮样式。
- 统一的线性 SVG 图标容器。
- 普通业务页和专业工作台两种壳层密度。
- 兼容现有页面的低优先级覆盖规则。

共享主题只覆盖外层品牌和导航元素，不重置专业工作台的画布、面板、节点或图表样式。

### 5.2 共享页面壳层

新增 `js/platform-shell.js`，集中维护：

- 页面文件名与页面标题的映射。
- 页面所属模块、导航激活项和面包屑。
- 学生、教师、管理员菜单配置。
- 专业实验页的父级页面和返回地址。
- 统一品牌标志和线性 SVG 图标集合。
- 不存在页面入口的禁用或演示提示行为。

脚本根据当前文件名和 `localStorage.userRole` 渲染合适导航。直接打开页面时使用安全默认角色，但不覆盖已有角色信息。

### 5.3 壳层类型

普通业务页面使用完整壳层：顶部品牌栏、角色导航、侧边菜单和主内容区。

工程仿真、2D/3D 设计器、嵌入式、Jupyter、区块链等专业工作台使用紧凑壳层：品牌标志、当前工具名称、面包屑以及“返回实验详情/实验大厅”按钮。专业工作台内部布局保持不变。

## 6. 页面跳转设计

### 6.1 课程

- 课程大厅的课程卡片和“开始学习/继续学习”按钮进入 `course-detail.html`。
- 课程详情提供返回课程大厅的入口。

### 6.2 实验

- 实验大厅进入实验详情。
- 实验详情的环境卡片继续承担选中和详情展示功能。
- “开始实验”根据当前选中卡片的 `data-env` 打开对应已有页面。
- 已实现环境映射：
  - `virtual-sim` → `engineering-simulation.html`
  - `3d-designer` → `3d-designer-enhanced.html`
  - `industry-cloud` → `industry-cloud.html`
  - `2d-designer` → `2d-designer.html`
  - `jupyter` → `jupyter-lab.html`
  - `blockchain` → `blockchain-lab.html`
  - `embedded` → `embedded-sim.html`
- 区块链基础仿真提供进入 `blockchain-dev.html` 的开发环境入口。
- 尚无独立页面的环境继续显示原有演示提示，不创建虚假链接。

### 6.3 考试

- 考试大厅继续进入 `exam-anti-cheat.html`。
- 防作弊考试页提供返回考试大厅的明确入口。

### 6.4 管理员死链

`user-management.html` 和 `system-settings.html` 当前不存在。对应入口改为禁用/演示项，点击后显示“演示模块暂未开放”，不得产生 404。

## 7. 角色状态

`js/app.js` 只应在登录页初始化时清理当前登录角色。普通业务页加载同一脚本时不得删除 `userRole` 和 `userName`。

主动退出仍清理登录状态并返回 `index.html`。角色导航以现有 `localStorage.userRole` 为准；没有角色信息时使用学生端作为安全默认值。

## 8. 品牌与视觉规范

### 8.1 品牌

- 中文品牌名：人工智能算法训练平台。
- Logo：几何化 `AI` 字母组合。
- 不在 Logo 和正式导航中使用机器人、书本、毕业帽等 Emoji。

### 8.2 色彩

- 保留蓝青色主色体系。
- 深蓝灰用于顶栏、侧栏和专业工作台框架。
- 青蓝色用于选中状态、主操作和关键数据。
- 成功、警告、错误颜色保留语义用途，不作为装饰色大面积使用。

### 8.3 组件风格

- 导航和功能入口使用统一线宽的内联 SVG 图标。
- 卡片采用轻边框、小圆角和低强度阴影。
- 减少蓝紫渐变、发光边框、悬浮上移及胶囊标签。
- 页面标题移除装饰性 Emoji。
- 普通管理页保持浅色内容区，专业工作台保持深色界面。

## 9. 兼容与错误处理

- 所有正式跳转均指向真实存在的 HTML 文件。
- 页面壳层脚本加载失败时，原页面内容和内部功能仍可使用。
- ECharts、Three.js 等外部资源加载失败时，不影响页面导航与返回能力。
- 对无实现页面的功能使用可理解的演示提示，不进行静默失败或 404 跳转。
- 对已有复杂页面只增加少量样式类和脚本引用，避免重排内部 DOM。

## 10. 验收标准

1. 所有正式 HTML 页面不存在指向缺失本地 HTML 文件的链接。
2. 课程大厅可以进入课程详情并返回。
3. 实验大厅可以进入实验详情。
4. 工程仿真、行业云、2D、增强版 3D、嵌入式、Jupyter、区块链仿真和区块链开发环境均有业务入口与返回路径。
5. 登录后的学生、教师、管理员角色在普通页面跳转时保持不变。
6. 正式页面品牌统一显示为“人工智能算法训练平台”。
7. Logo 与正式导航不再使用 Emoji，统一使用线性 SVG 图标。
8. `user-management.html` 和 `system-settings.html` 不再产生 404。
9. 专业工具页的已有按钮、弹窗、画布和 Mock 交互保持可用。
10. 当前工作区原有未提交修改得到保留。

## 11. 验证策略

- 使用静态链接检查脚本扫描所有 HTML、`href` 和显式 JavaScript 跳转。
- 检查正式业务页的品牌名、主题文件和壳层脚本引用。
- 检查实验环境映射覆盖所有已有专业页面。
- 检查角色状态的读写位置，确保只有登录和退出流程会清理状态。
- 对登录、课程、实验、考试及代表性专业工作台执行浏览器烟雾测试。
- 最后检查 Git 差异，确认没有覆盖工作区原有修改。
