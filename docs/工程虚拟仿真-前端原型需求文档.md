## 一、页面整体布局

采用**三栏式布局**，结构如下：

```
┌─────────────────────────────────────────────────────────────┐
│  [顶部工具栏] 面包屑 | 操作按钮组 | 状态控制 | 智能体入口 | 用户  │
├──────────┬──────────────────────────────────┬─────────────┤
│          │                                  │             │
│  设备库   │         仿真画布（网格背景）        │  属性/AI    │
│  侧边栏   │         设备拖拽 + 连线            │  右侧面板   │
│          │                                  │  (可折叠)   │
│  树形分类 │         右键菜单支持              │             │
│  搜索框   │                                  │             │
│          │                                  │             │
└──────────┴──────────────────────────────────┴─────────────┘
```

### 1.1 尺寸规范
- 整体：`width: 100vw; height: 100vh; overflow: hidden;`
- 左侧设备栏：`width: 260px; min-width: 200px;` 可拖拽调整宽度
- 右侧AI面板：`width: 360px;` 可折叠/展开
- 中间画布：`flex: 1;` 自适应剩余空间
- 顶部工具栏：`height: 48px;`

### 1.2 配色方案
- 主背景：`#f5f7fa`（浅灰蓝）
- 画布背景：`#ffffff`，网格线 `#e8e8e8`
- 左侧栏背景：`#ffffff`，边框 `#e4e7ed`
- 顶部栏背景：`#ffffff`，底部阴影 `0 1px 4px rgba(0,0,0,0.08)`
- 主色调：`#409eff`（Element蓝），悬停 `#66b1ff`
- 设备卡片：`#ffffff`，边框 `#dcdfe6`，悬停边框 `#409eff`
- 连线颜色：
  - 电源正极（VCC）：`#f56c6c`（红色）
  - 信号线（DATA）：`#409eff`（蓝色）
  - 地线（GND）：`#303133`（黑色）
  - 选中状态：`#67c23a`（绿色高亮）

## 四、中间仿真画布（Canvas）

### 4.1 画布背景
- **网格**：`background-image: linear-gradient(#e8e8e8 1px, transparent 1px), linear-gradient(90deg, #e8e8e8 1px, transparent 1px);`
- **网格大小**：`background-size: 20px 20px;`
- **画布范围**：理论上无限大，但原型中限制为固定区域（如 2000x2000），支持拖拽滚动

### 4.2 设备组件（画布上）

#### 4.2.1 设备卡片通用样式
```css
.device-component {
  position: absolute;
  width: 120px;
  background: #ffffff;
  border: 1px solid #dcdfe6;
  border-radius: 6px;
  box-shadow: 0 2px 8px rgba(0,0,0,0.08);
  padding: 8px;
  cursor: move;
  user-select: none;
}
.device-component:hover {
  border-color: #409eff;
  box-shadow: 0 4px 12px rgba(64,158,255,0.2);
}
.device-component.selected {
  border-color: #67c23a;
  box-shadow: 0 0 0 2px rgba(103,194,58,0.3);
}
```

#### 4.2.2 具体设备类型（根据截图）

**1. 电源模块（12V Power Supply）**
- 外观：灰色矩形，顶部标签"12V Power Supply"
- 端口：左侧黄色圆形（VCC+），中间红色圆形（VCC+），右侧黑色圆形（GND-）
- 端口样式：圆形，直径16px，带颜色标识

**2. 网关（ChipStack网关）**
- 外观：蓝色设备，顶部两根黑色天线
- 端口：底部多个蓝色/红色圆形连接点
- 标签：蓝色背景白字 "ChipStack网关"

**3. 采集器（485型）**
- 外观：黑色矩形设备，顶部两根天线
- 标签："地址码:(hex)d"
- 端口：底部485接口（蓝色/红色端子）

**4. 控制柜**
- 外观：大型灰色机柜，带显示屏和按钮
- 标签：无文字标签，纯图形

**5. 水质PH传感器**
- 外观：蓝色标签设备
- 标签："485型 水质PH传感器 地址码:(hex)5"
- 端口：底部多色接线端子

**6. 各类传感器（底部区域）**
- 外观：黑色圆柱形/方形传感器
- 端口：顶部多色接线（黄红黑蓝）
- 底部连接24V Power Supply

### 4.3 连线系统（Wire System）

#### 4.3.1 连线规则
- **起点**：从一个设备的输出端口拖拽到另一个设备的输入端口
- **连线类型自动识别**：
  - 从VCC端口出发 → 红色线（电源）
  - 从DATA端口出发 → 蓝色线（信号）
  - 从GND端口出发 → 黑色线（地线）
- **连线样式**：
  - 线宽：2px
  - 拐角：直角（曼哈顿路由）或斜线（直接连接）
  - 悬停：线宽变为3px，显示删除按钮（×）

#### 4.3.2 SVG连线实现
```html
<svg class="wire-layer" style="position:absolute; top:0; left:0; width:100%; height:100%; pointer-events:none;">
  <path d="M100,200 L200,200 L200,300" 
        stroke="#f56c6c" 
        stroke-width="2" 
        fill="none"
        style="pointer-events:stroke;"
        class="wire-power"/>
</svg>
```

#### 4.3.3 连线验证（★核心功能）
- 开启"连线验证"时：
  - 正确连线：连线变为绿色，端口显示 ✅
  - 错误连线：连线变为红色虚线，端口显示 ❌，顶部显示错误提示
- 验证面板：点击"连线验证"下拉，显示验证结果列表
  ```
  ┌──────────────┐
  │ 连线验证结果   │
  ├──────────────┤
  │ ✅ 电源连接正常 │
  │ ✅ 信号线正确   │
  │ ❌ 地线未连接   │ ← 红色高亮
  │ ✅ 网关配置正确 │
  └──────────────┘
  ```

### 4.4 右键菜单（Context Menu）
在画布或设备上右键弹出：
```
┌──────────────┐
│ 复制         │
│ 粘贴         │
│ 删除         │
│ 置顶         │
│ 置底         │
├──────────────┤
│ 属性设置...   │ ← 点击打开右侧属性面板
│ 查看文档...   │
└──────────────┘
```

### 4.5 画布操作
- **缩放**：Ctrl+滚轮 或 顶部缩放按钮（100% / 75% / 50% / 125% / 150%）
- **平移**：按住空格+拖拽 或 滚动条
- **框选**：按住Shift+拖拽，显示蓝色半透明选择框
- **多选**：Ctrl+点击多个设备

## 八、场景切换功能（▲重点）

点击"默认场景"下拉，切换场景时：

### 8.1 场景列表
- `智慧牧场`：显示牧场设备（温湿度、风扇、喂食器等）
- `智慧家居`：显示家居设备（灯光、空调、门锁、窗帘等）
- `智慧温室`：显示温室设备（光照、CO2、灌溉、通风等）

## 十、交互细节规范

### 10.1 拖拽交互
```javascript
// 设备拖拽伪代码
device.on('mousedown', (e) => {
  const startX = e.clientX - device.offsetLeft;
  const startY = e.clientY - device.offsetTop;

  document.on('mousemove', (e) => {
    device.style.left = e.clientX - startX + 'px';
    device.style.top = e.clientY - startY + 'px';
    updateWires(); // 实时更新连线
  });

  document.on('mouseup', () => {
    document.off('mousemove');
    document.off('mouseup');
  });
});
```

### 10.2 连线交互
```javascript
// 端口连线伪代码
port.on('mousedown', (e) => {
  const wire = createWire();
  wire.startPort = port;

  document.on('mousemove', (e) => {
    wire.updateEnd(e.clientX, e.clientY);
  });

  document.on('mouseup', (e) => {
    const targetPort = getPortAt(e.clientX, e.clientY);
    if (targetPort && targetPort !== port) {
      wire.endPort = targetPort;
      wire.validate(); // 验证连线正确性
    } else {
      wire.remove();
    }
  });
});
```

### 10.3 动画规范
- 面板滑入：`transform: translateX(100%) → translateX(0)`，300ms，cubic-bezier(0.25, 0.1, 0.25, 1)
- 设备放置：`scale(0.8) → scale(1)`，200ms，ease-out
- 连线绘制：`stroke-dasharray` 动画，500ms
- 消息出现：`translateY(10px) opacity(0) → translateY(0) opacity(1)`，200ms
- 模拟指示灯闪烁：`opacity: 1 → 0.3 → 1`，1s，infinite
