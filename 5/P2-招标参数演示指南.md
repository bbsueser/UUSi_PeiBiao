#  招标参数演示指南

## 1. 文档用途

本指南用于录制 P2 原型的投标演示视频，覆盖以下参数：

- ▲1 知识库与垂类大模型 AI 图文问答
- ▲4 实时连线验证开启、关闭及错误检测
- ▲5 设备通信消息面板
- ▲6 定值、随机值模拟数据源
- ▲d 11 类无线传感器
- ▲10 仿真数据与开源物联网云平台交互、云端控制执行器
- ▲13 零代码模型训练、验证、部署及端侧推理

本项目为交互原型，AI、云平台、训练过程和边缘终端均使用本地模拟数据。录屏时应表述为“原型模拟演示”，不要声称已经连接真实生产服务。

## 2. 演示前准备

### 2.1 启动项目

演示机仅需 Python 环境（无需安装 Node）。解压交付包后，进入其中的 `dist` 目录，启动静态服务：

```bash
cd 解压目录/dist
python -m http.server 4173 --bind 127.0.0.1
```

浏览器打开：

```text
http://127.0.0.1:4173
```

说明：

- 若本机命令为 `python3`，将上述 `python` 替换为 `python3`。
- 去掉 `--bind 127.0.0.1` 可允许局域网内其他设备访问。
- 全部 7 个演示参数（▲1 / ▲4 / ▲5 / ▲6 / ▲d / ▲10 / ▲13）均为前端本地模拟，纯静态服务即可完整演示，无需后端接口。

> 备选：若演示机已安装 Node，也可在工程根目录执行 `npm install && npm run dev`，访问 http://127.0.0.1:3000 ，效果一致。

### 2.2 录屏建议

- 建议使用 1920×1080 分辨率，浏览器缩放保持 90%～100%。
- 使用学生身份进入“人工智能算法训练平台”。
- 全程使用同一个浏览器标签页，保证工程仿真与行业云之间的模拟状态能够延续。
- 每次点击后停留 2～3 秒，让按钮状态、提示消息和动态数据完整进入画面。
- 正式录制前按本指南完整走一遍，确认没有残留弹窗。

## 3. 推荐录屏顺序

建议按照以下顺序录制，避免重复进入环境：

1. AI 技能助手：演示参数 ▲1。
2. 工程虚拟仿真：连续演示参数 ▲4、▲5、▲6、▲d，并同步设备到行业云。
3. 行业云控制台：演示参数 ▲10。
4. 人工智能平台-Jupyter：演示参数 ▲13，先做「一键自动演示」展示整体链路，再手动分步演示重点画面。

完整演示建议控制在 8～12 分钟。

### 预期画面

- 用户问题与 AI 回复形成完整对话。
- 回复同时包含文字和配图。
- 页面显示课程知识库命中来源，体现“知识库检索 + 垂类 AI 问答”的演示链路。

### 建议解说词

### 录屏取证重点

同一画面中尽量同时保留“用户问题”“图文回答”和“知识库检索命中”三部分。

## 5. ▲4 实时连线验证开启、关闭及错误检测

### 页面入口

顶部导航 → **实验大厅** → **工程虚拟仿真** → 启动环境 → **进入控制台**。

### 操作步骤

1. 进入控制台，确认顶部环境状态为“未开启”，并确认 **连线验证已关闭**。
2. 在关闭状态下点击 **开始检测**，展示系统提示“连线验证已关闭，请开启后再进行检测”。
3. 点击连线验证开关，使其变成 **连线验证已开启**。
4. 再次点击 **开始检测**，等待检测完成，发现 1 条异常连线。
5. 展示检测结果中的异常连线（继电器 OUT ➔ 风机 IN）、错误原因（动力主干线未通电 / 双极空中虚接）和处理建议。
6. 点击 **自动补全修复连线**，补全电源回路；再点击 **开始检测**，展示异常数量清零、“全部连线通过”。
7. 完成自检后点击顶部 **启动仿真**，等待按钮变成“仿真运行中”（前置门禁要求连线自检通过才允许启动）。
8. 展示底部通信/操作日志中同步写入的检测记录。
9. 最后再次关闭连线验证，证明该功能可以随时开启和关闭。

### 预期画面

- 开关状态在“已关闭”和“已开启”之间变化。
- 关闭时阻止检测并给出提示。
- 开启后检测出 1 条异常连线。
- 修复后重新检测通过，检测记录同步写入底部日志。
- 自检通过后才允许启动仿真，启动后进入“运行中”。

### 建议解说词

> 仿真实训系统提供可控制的实时连线验证。验证关闭时不执行检测；开启后系统会检查供电、端口及通信链路，定位异常并给出修复建议。完成修复后可以重新检测，形成发现问题、处理问题和复检确认的完整闭环。

### 建议解说词

> 系统内置设备通信消息面板。启动仿真后，面板会实时显示 Modbus 采集报文和 MQTT 云端转发消息，学生可以观察设备通信过程并辅助定位协议配置问题。

## 7. ▲6 定值、随机值模拟数据源

### 页面入口

继续停留在 **工程虚拟仿真控制台**。

### 操作步骤

1. 在仿真画布中点击 **温湿度传感器**。
2. 在右侧配置参数中找到 **模拟数据模式方式**。
3. 展示 **定值和随机值**，将温度设置为一个明显数值，例如 `26.5`，点击 **发送一次**。
4. 展示“实时上报数据流”和底部通信消息中的固定值。
5. 将模式切换为 **随机值**，设置温度、湿度的 Min 和 Max 范围。
6. 点击 **开始生成**，等待出现多条不同数值。
7. 展示数值在设定范围内变化，然后点击 **停止生成**。

### 预期画面

- 模式选项至少包含“定值”和“随机值”。
- 定值模式产生设定值。
- 随机值模式连续产生不同数值。
- 生成结果同时进入实时数据流和通信消息面板。

### 建议解说词

> 仿真硬件可以作为模拟数据源。定值模式适合复现固定工况，随机值模式可以按上下限模拟传感器波动；产生的数据会同步写入设备数据流和通信消息。

## 9. ▲10 仿真数据与开源物联网云平台交互

### 页面入口

先在 **工程虚拟仿真控制台** 完成同步，再进入 **实验大厅** → **行业云** → **进入控制台**。

### 操作步骤

#### 第一段：仿真数据上云

1. 在工程虚拟仿真页面确认仿真处于运行状态。
2. 在画布右下角找到 **云平台对接** 面板。
3. 点击 **同步设备到云平台**。
4. 展示状态变为“已同步至行业云平台”“实时上报中”，并显示已注册节点数量。
5. 返回实验大厅并进入 **行业云**，不要刷新浏览器。

#### 第二段：云平台显示数据

1. 在行业云控制台打开 **平台总览** 或 **设备管理**。
2. 展示同步后的设备、实时遥测数值和历史数据曲线。
3. 打开 **数据仿真**，展示固定值、随机值任务及执行记录。

#### 第三段：云端控制执行器

1. 打开 **任务管理**，选择 **属性下发**，目标选择风机，属性为 `fanStatus`，值为 `on`。
2. 点击 **测试下发**，先展示执行记录为“等待回执”，不要把发送动作直接解说为执行成功。
3. 返回工程虚拟仿真；运行状态会保留，页面读取待执行指令并更新风机状态。
4. 展示工程操作日志中的云端下行指令和带 commandId 的设备回执。
5. 再进入行业云任务管理，确认同一条记录已由“等待回执”更新为“成功”，并显示设备执行详情。
6. 使用 `off` 再演示一次关闭；最后关闭工程仿真环境，回到行业云确认设备离线、遥测停止、下发按钮禁用。

### 预期画面

- 仿真页面显示设备已同步、遥测实时上报。
- 行业云显示传感器实时数据和历史记录。
- 云端下发后先显示等待回执，工程仿真执行后才更新为成功。
- 工程仿真侧读取控制命令、更新执行器状态并写入通信/操作日志。
- 关闭仿真后行业云显示离线，保留最后一次遥测但停止更新。

### 建议解说词

> 仿真实训数据可以同步到行业云控制台。控制台按开源物联网平台常见的产品、设备、物模型和遥测结构展示数据，同时支持向风机、继电器等仿真执行器下发控制指令，形成数据上行和指令下行的双向交互闭环。本演示使用本地模拟链路，无需连接真实云服务。

## 10. ▲13 零代码可视化模型训练与边缘部署

### 页面入口

顶部导航 → **实验大厅** → **人工智能平台-Jupyter** → 启动环境 → **进入控制台**。

进入控制台后，默认打开 **零代码可视化实训** 标签页（顶部标签第一个，Sparkles 图标），即 **★ 零代码可视化分类/检测模型训练与边缘端推理实训系统**。

### 界面结构说明

进入后停留 3 秒，先向镜头展示整体布局，方便后面对照：

- **顶部靛蓝横幅**：实训系统标题、“一键自动演示完整实验链路 (Auto Track)”按钮和“实验重置”按钮。
- **左侧步骤栏**：工作流程步骤控制，共 8 步（任务模式与模型拉取 → 数据载入与异常增强 → 混合平衡样本生成 → 超参数阻力调整 → 激发边缘多Epoch训练 → 模型离线验证判定 → 部署免编程计算终端 → 板端传感器推理实测），底部显示“实训运行度 X / 8 指标已就绪”进度条。
- **中间工作区**：根据步骤展示对应的可视化配置与结果面板。
- **右侧终端**：PYTORCH 边缘联机终端日志（深色终端），实时滚动输出每一阶段的日志。

### 推荐操作一：一键自动演示完整链路（Auto Track）

1. 确认工作区处于步骤 1。
2. 点击右上角 **一键自动演示完整实验链路 (Auto Track)**。
3. 保持页面不切换，等待约 14～15 秒，流程会自动推进 8 个步骤：
   - **第 1 步**（约 1s）：自动选择“图像分类”任务模式，拉取 PyTorch ResNet50 预训练权重；
   - **第 2 步**（约 2s）：触发无监督数据预处理增强（色彩抖动、随机镜像、白噪声过滤），进度推进至 100%，生成 400 张高清增强图像，并展示 4 张小图“增强矩阵快照预览”；
   - **第 3 步**（约 4.5s）：执行少数样本加权采样，按 7:2:1 划分训练集 280 张 / 验证集 80 张 / 测试集 40 张，生成 COCO 标准 label_map.json；
   - **第 4 步**（约 6s）：下发超参数配置（Learning_rate: 0.001, Optimizer: Adam），写入 `/work/visual_train/output/train_log.json`；
   - **第 5 步**（约 7s）：开启在线可视化训练，损失曲线快速下降、精度曲线快速上升，刷新至 Epoch 20/20 后收敛，捕获本地最优权重 `best_model.pth [14.2 MB]`；
   - **第 6 步**（约 11s）：载入 10% 独立验证集，输出混淆矩阵诊断报告，对角命中率 98.2%、检测准确度 98.2%、推理时延 11-14 ms，绿色印章“精度达标，准予部署”；
   - **第 7 步**（约 12.5s）：边缘终端 SSH 联机成功，ONNX 算子推送进度 0→100%，部署完成（端口映射 3000 → 边缘终端）；
   - **第 8 步**（约 14.5s）：端侧实时推理猫图像，显示检测框与置信度 `indoor_device : 98.7%`，RaspberryPi Cam Live [60 FPS]。
4. 结束时等待右侧“实训运行度”变为 **8 / 8 指标已就绪**，画面出现“🎉 一键完整模型训练与端侧部署演示链路成功跑通！”提示。
5. 顺手点击 **推理截图存证**，展示推理结果被截取归档。

### 推荐操作二：手动分步演示（录制重点画面）

如需逐段重点录制，建议以下顺序手动操作（每步先展示、后点击）：

**第 1 步：任务模式与模型拉取**
- 点击 **图像分类** 卡片（或 **目标检测与识别** 卡片以演示第二种任务）。
- 分类任务可在「ResNet50 / MobileNetV3 / SqueezeNet」中选择；切换为目标检测后骨架切换为「YOLOv5s / YOLOv8n / Faster-RCNN」。
- 点击 **一键拉取并部署预训练参数模型**，按钮变为“预训练权重已部署及挂载”。

**第 2 步：外部标注数据载入与无监督预处理增强**
- 展示清洗预备选项复选框：清除异形比例/异常白噪声图、相似灰度图片去重去影、随机镜像反转、15° 视角随机几何微旋转。
- 展示源数据集状态（40 张原始图像，cat/dog 双目标分类）。
- 点击 **立刻激活数据预处理增强**，进度条走完并展示 4 张增强矩阵小图（RandomFlip / Rotate15 / ColorJitter / Cleaned）。

**第 3 步：数据自动生产与黄金样本分割 (7:2:1)**
- 展示“训练集 280 张 (70%) / 验证集 80 张 (20%) / 独立测试 40 张 (10%)”三个统计卡片。
- 展示 label_map.json、annotation_coco.json 生成选项。
- 点击 **执行样本自动配重生成**，进度条走完。

**第 4 步：核心深度模型超参数阻力调整**

## 12. 常见问题处理

- **点击实验后页面状态不对**：返回实验大厅重新进入；当前版本会保留合法的实验页面和环境状态。
- **通信消息为空**：先点击“启动仿真”，等待状态变为“仿真运行中”。
- **云平台没有同步设备**：先在工程仿真右下角点击“同步设备到云平台”，并保持同一浏览器标签页。
- **Jupyter 没有进入零代码实训界面**：确认已经点击“进入控制台”而不是停留在环境详情页；进入后默认停在“零代码可视化实训”标签页。
- **一键自动演示中途画面卡顿**：浏览器保持前台并停留不动；如需重来，等待本轮结束或点击“实验重置”再启动。
- **训练曲线没有出现数值**：确认点击“一键开展多轨在线模型训练”前已保存超参数（“保存并注入超参数到本地容器”）。
- **录屏画面内容过多**：浏览器缩放调整到 90%，不要低于 80%，避免文字难以辨认。
