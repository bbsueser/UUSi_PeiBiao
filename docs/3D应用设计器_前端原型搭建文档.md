### 2.1 顶部导航栏 (Header)

**组件：** `Header.tsx`

**功能需求：**

- 显示品牌Logo（NLECloud + 应用设计器3D）
- 当前应用名称展示（"当前应用：asdasd"）
- 用户信息显示（右上角：郑鸿杰）
- 操作按钮组：清除、保存、预览、发布

**接口定义：**

```typescript
interface HeaderProps {
  appName: string;

  onClear: () => void;
  onSave: () => void;
  onPreview: () => void;
  onPublish: () => void;

// 状态管理
interface AppState {
  currentApp: {
    id: string;
    name: string;
    status: 'editing' | 'saved' | 'published';

  currentUser: {
```

**UI结构：**


### 2.3 3D主画布 (MainCanvas)

**组件：** `MainCanvas.tsx` / `Scene3D.tsx`

**功能需求：**

- 基于 Three.js / Babylon.js 的3D渲染
- 天空盒环境（蓝天白云）
- 地面网格
- 模型加载与展示
- 相机控制（旋转/平移/缩放）
- 模型选中高亮
- 标签悬浮显示（如"光照度传感器"）

**技术选型：**

```typescript
// 推荐使用 Three.js + React Three Fiber
```

```typescript
interface Scene3DProps {
  models: PlacedModel[];

  position: { x: number; y: number; z: number };

  fog: boolean;
```

**数据源配置：**

```typescript
// 云平台设备数据
interface CloudDataSource {
  type: 'cloud-platform';
  platformUrl: string;
  apiKey: string;
  deviceList: CloudDevice[];
}

interface CloudDevice {
  deviceId: string;
  deviceName: string;
  properties: DeviceProperty[];
}

interface DeviceProperty {
  name: string;
  type: 'string' | 'number' | 'boolean' | 'enum';
  unit?: string;
  currentValue: any;
  lastUpdate: string;
}

// 工程虚拟仿真平台
interface SimulationDataSource {
  type: 'simulation-platform';
```

```typescript
// WebSocket连接管理
class DataConnectionManager {
  private ws: WebSocket | null = null;

  connect(config: DataSourceConfig): void {
    this.ws = new WebSocket(config.platformUrl);
    this.ws.onmessage = (event) => {
      const data = JSON.parse(event.data);
      this.updateModelState(data);
    };
  }

  // 根据设备属性值更新组件状态
  updateModelState(data: DeviceData): void {
    const model = findModelByDeviceId(data.deviceId);
    if (model) {
      // 更新属性值
      model.properties = { ...model.properties, ...data.properties };
      // 触发状态变化（如：报警器闪烁）
      this.triggerStateChange(model, data.properties);
    }
  }

  // 状态变化触发视觉反馈
  triggerStateChange(model: PlacedModel, properties: any): void {
    // 例如：报警器属性 alarm=true 时，模型变红并闪烁
    if (properties.alarm === true) {
      model.visualState = 'alarming';
      model.animations.push('flash-red');
    }
  }
}
```

## 五、交互流程

### 5.1 模型拖拽放置

```
1. 用户在左侧模型库点击/拖拽模型
2. 拖拽进入3D画布区域
3. 计算鼠标射线与地面的交点
4. 在交点位置创建模型实例
5. 自动选中并打开属性面板
6. 支持继续拖拽调整位置
```

### 5.2 属性编辑流程

```
1. 点击3D模型选中
2. 右侧显示属性面板
3. 编辑位置/缩放/旋转（实时预览）
4. 配置数据绑定（动态/静态）
5. 配置标签/导航/语音
6. 点击确定保存
7. 自动同步到场景状态
```

### 5.3 数据对接流程

```
1. 选择模型 → 打开数据配置
2. 选择数据源类型（云平台/仿真平台）
3. 连接平台获取设备列表
4. 选择对应设备
5. 映射设备属性到模型属性
6. 设置刷新间隔
7. 开启实时数据订阅
8. 数据变化自动更新模型状态
```

### 5.4 导入导出流程

**【导出】**

```
1. 点击导出按钮
2. 选择导出格式（JSON/完整包）
3. 后端组装数据
4. 生成文件并下载
```

**【导入】**

```
1. 点击导入按钮
2. 选择文件上传
3. 解析并验证数据
4. 加载模型资源
5. 重建场景和数据绑定
6. 提示导入结果
```
