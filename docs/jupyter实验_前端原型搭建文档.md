# Jupyter实验平台前端原型开发指令 (Prompt for AI Code Generator)

> 请根据本文档生成一个功能完整的 Jupyter 实验平台前端原型工程。

## 1. 项目概述

构建一个面向数据科学与人工智能教学的 Jupyter 实验平台，教师和学生可通过浏览器完成代码实验、模型训练、模型部署与终端实训等操作。前端需呈现以下核心模块：

- **Jupyter 实验工作台**
- **可视化模型训练工具**
- **模型预测部署与展示**
- **终端实训模式**
- **预置模块与沙箱环境管理**

---

## 2. 路由设计

| 路径 | 页面组件 | 说明 |
|------|----------|------|
| `/` | `Dashboard` | 首页/实验列表 |
| `/lab/:notebookId` | `LabWorkbench` | Jupyter 实验工作台 (Notebook 编辑与运行) |
| `/train` | `ModelTrainer` | 零代码可视化模型训练工具 |

所有页面应包含公共的顶部导航栏，支持页面间切换。

## 3. 功能模块详细需求

### 3.1 Jupyter 实验工作台 (`LabWorkbench`)

#### 3.1.1 页面布局
- 左侧：**预置模块面板** + 文件列表
- 中间：**Notebook 编辑器** (模拟 Jupyter 单元格)
- 右侧（可收起）：**图表 / 输出预览区** 或 **属性面板**

#### 3.1.2 预置模块面板
展示平台预置的代码模块，学员可直接引用调用，需包含以下分类：
- **字符串数据处理模块**：提供常用字符串操作函数列表，点击可插入示例代码。
- **数据请求模块**：支持 HTTP 请求、API 调用示例。
- **图表可视化模块**：基于 pyecharts 的图表生成代码片段（如柱状图、折线图等，标注引用了 `pyecharts`）。
- **数据整理模块**：数据清洗、透视、合并等代码片段。
- **自然语言分词模块**：如 jieba 分词示例代码。
- 每个模块项可点击，自动在当前选中的 Notebook 单元格中插入对应的代码模板。

#### 3.1.3 Notebook 编辑器
- 支持 **添加/删除/移动单元格** (代码单元格、Markdown 单元格)。
- 代码单元格使用 `monaco-editor` 或简易的代码编辑器模拟（为了原型快速实现，也可用 `textarea` 配合语法高亮，但建议集成 `@monaco-editor/react`）。
- 执行按钮：点击运行当前单元格，在输出区显示模拟结果（文本、表格、图片、图表 HTML 等）。原型中执行过程用 setTimeout 模拟，并根据代码内容返回预定义的 Mock 输出。
- 必须实现 **导入 ipynb 文件** 的功能：通过文件选择器加载 `.ipynb` 文件，解析 JSON 并将单元格内容渲染到 Notebook 中。
- 必须实现 **导出 ipynb 文件** 的功能：将当前所有单元格内容按 `nbformat` 规范组织为 JSON，触发下载 `.ipynb` 文件。

#### 3.1.4 任务重置功能
- 每个账户拥有独立沙箱环境（界面顶部展示当前环境状态标识，如“沙箱已激活”）。
- 重置按钮：点击后弹出二次确认弹窗，说明“将清空所有配置、文件及运行输出，并恢复默认参数”。
- 确认重置后：清空所有 Notebook 单元格内容，恢复预置示例笔记本，并可随机变换模拟的规则参数（展示“参数已更新：训练轮次由10变为20”之类的提示），支持学员反复进行数据分析训练。

#### 3.1.5 pyecharts 图表与组合报告
- 当执行图表相关代码时，输出区域需渲染交互式图表。原型中直接内嵌 **ECharts** 实例模拟 pyecharts 图表效果。
- 需预置至少 5 种常用图表模板（柱状图、折线图、散点图、饼图、地理图等），并可通过按钮切换展示更多，强调“支持 30+ 图表”。
- 支持 **组合图表报告设计**：允许用户将多张图表拖入一个报告画布，生成并导出为组合报告（原型可生成截图或 HTML 导出）。

### 3.2 可视化模型训练工具 (`ModelTrainer`)

实现零代码构建分类/检测模型的分步向导，包含以下步骤卡片（步骤条布局）：

1. **数据上传与预处理**
   - 上传标注数据（zip）的模拟，上传后显示数据概览（样本数量、标注类别等）。
   - 提供“数据预处理”选项：如图像尺寸调整、归一化等参数设置。
2. **数据生产**
   - 展示数据集划分（训练集/验证集/测试集比例滑块），生成生产日志。
3. **训练参数配置**
   - 选择预训练模型（下拉：ResNet、MobileNet、YOLO等，标识“分类/检测”）。
   - 配置学习率、批次大小、训练轮次等表单。
4. **模型训练**
   - 点击开始训练，模拟训练过程（进度条、损失/准确率动态曲线）。
   - 可随时暂停/停止。
5. **模型验证**
   - 展示验证集指标（准确率、混淆矩阵等）。
   - 可上传单张图片进行预测验证，显示分类结果/检测框。
6. **模型部署**
   - 训练完成后，提供“直接部署到边缘计算终端”按钮。点击后模拟部署流程，展示成功状态，强调无需交叉编译。

### 3.3 模型预测应用部署与展示 (`ModelDeploy`)

- 页面分为“部署管理”和“在线预测”两个 Tab。
- **部署管理**：列表展示已部署的模型应用，支持新建部署。新建时填写应用名称、选择模型（图像分类/目标检测）、设置边缘终端标识。
- **在线预测效果展示**：提供一个 Web 界面，可 **上传图片**，模拟调用已部署模型进行预测，并展示结果：
  - 图像分类：返回 Top-5 类别及置信度。
  - 目标检测：在原图上绘制检测框，并标注类别。
- 此模块需体现模型预测效果的 Web 页面展示。

### 3.4 终端实训模式 (`TerminalMode`)

- 页面默认 **左右分屏**：
  - 左侧：**实训手册**（渲染 Markdown 内容，包含课件文字、代码示例等）。
  - 右侧：**终端环境**（使用 `xterm.js` 模拟 Web 终端，支持命令行操作）。
- 提供 **模式切换按钮**：
  - **仅文档模式**：左侧手册全屏，隐藏终端。
  - **全屏终端模式**：右侧终端全屏，隐藏手册。
  - **同屏模式**：恢复左右分屏。
- 分屏比例可通过拖拽分隔条调整。
- 终端内预置几个模拟命令（如 `ls`, `cat data.txt`, `python train.py` 等），执行时显示与手册相关的输出，增强实训体验。
