# 区块链智能合约开发环境原型搭建需求文档 (V1.0)

## 一、项目概述

### 1.1 项目背景
随着区块链技术的普及，智能合约开发成为相关学习与教学的核心环节。传统开发依赖本地环境搭建（如安装Solidity编译器、Ganache、Truffle等），存在环境配置复杂、兼容性差、维护困难等问题。为解决这一痛点，需构建一个**免安装、全功能、云端集成**的区块链智能合约开发环境，支持在线编写、编译、调试、部署合约，降低学生学习门槛，提升实验效率。

### 1.2 平台目标
- 提供完整的在线智能合约开发环境，无需本地安装任何工具
- 集成文件管理器、代码编辑器、调试控制台、运行环境
- 支持合约编译、部署、执行、静态分析与单步/断点调试
- 内置JavaScript虚拟机（JSVM）与Web3注入环境，模拟真实链上交互
- 支持结果可视化展示与错误定位
- 界面风格参考Remix IDE，兼顾专业性与易用性

### 2.2 文件管理器模块（左侧）

#### 2.2.1 功能需求
- 支持创建、删除、重命名、移动文件/文件夹
- 支持上传本地文件（拖拽或点击上传）
- 支持从浏览器本地存储（LocalStorage / IndexedDB）加载/保存项目
- 支持项目模板创建（如：空项目、ERC20模板、投票合约模板等）
- 支持文件树结构展示，可折叠/展开目录
- 支持文件类型图标识别（.sol, .js, .json, .txt 等）

#### 2.2.2 界面元素
- 标题：“文件浏览器”
- 搜索框：“请输入组件名”（支持文件名模糊搜索）
- “+ Create” 按钮：下拉菜单支持创建文件/文件夹/项目
- 文件树节点：带图标、名称、类型标识
- 右键菜单：支持“重命名”、“删除”、“下载”、“复制路径”

#### 2.2.3 交互要求
- 点击文件 → 在中间编辑器打开
- 双击文件 → 编辑模式
- 拖拽上传 → 支持 .sol 文件自动识别并提示创建合约
- 文件修改后自动保存至本地存储（或手动保存）

---

### 2.3 代码编辑器模块（中间）

#### 2.3.1 功能需求
- 支持Solidity语言语法高亮、自动补全、错误提示
- 支持多文件标签页（类似VS Code）
- 支持代码折叠、查找替换、跳转到定义
- 支持合约编译错误实时提示（行号+错误信息）
- 支持保存、另存为、格式化代码（Prettier/Solhint）

#### 2.3.2 界面元素
- 标签页：显示当前打开的文件名（如 Home.sol）
- 编辑器区域：深色主题，行号、缩进、语法高亮
- 状态栏：显示光标位置、文件编码、语言模式
- 编译按钮：触发合约编译，输出结果至右侧面板

#### 2.3.3 交互要求
- 编译成功后 → 自动生成ABI、Bytecode，显示在调试面板
- 编译失败 → 高亮错误行，弹出错误列表
- 支持快捷键：Ctrl+S保存，F5运行，F9调试

---

### 2.4 调试与运行环境模块（右侧）

#### 2.4.1 功能需求
- **运行环境**：内置JavaScript虚拟机（JSVM），模拟以太坊环境
- **Web3注入**：自动注入Web3对象与Web3 Provider，支持合约部署与调用
- **调试功能**：
  - 单步执行（Step Over / Step Into / Step Out）
  - 设置/取消断点（点击行号左侧）
  - 查看变量值、调用栈、内存/堆栈状态
- **部署功能**：
  - 选择部署账户（模拟账户）
  - 设置Gas Limit / Gas Price
  - 部署合约并生成合约地址
- **执行功能**：
  - 调用合约函数（只读/写入）
  - 输入参数（支持基础类型、数组、结构体）
  - 显示返回值、交易哈希、事件日志

#### 2.4.2 界面元素
- 标签页：“调试控制台”、“Web3环境”、“运行结果”
- 调试控制按钮：播放、暂停、停止、单步、断点开关
- 变量监视面板：显示当前作用域变量名、值、类型
- 调用栈面板：显示函数调用层级
- 部署配置区：账户选择、Gas设置、合约选择
- 执行结果区：返回值、交易状态、事件输出、错误信息

#### 2.4.3 交互要求
- 设置断点 → 行号左侧出现红点
- 单步执行 → 高亮当前执行行，变量面板实时更新
- 部署合约 → 成功后显示合约地址，可复制
- 调用函数 → 输入参数后点击“执行”，结果显示在下方
- 支持“重新部署”、“重置环境”按钮

---

### 2.5 运行结果与分析模块（底部/侧边）

#### 2.5.1 功能需求
- 显示合约执行结果（成功/失败、返回值、Gas消耗）
- 显示静态分析结果（如：未使用的变量、潜在安全问题）
- 支持导出运行日志（JSON / TXT）
- 支持合约字节码、ABI、函数签名的可视化展示

#### 2.5.2 界面元素
- 标签页：“运行结果”、“静态分析”、“日志导出”
- 结果展示区：结构化文本 + 高亮关键信息
- 分析提示：列出潜在问题，带风险等级（低/中/高）
- 导出按钮：支持导出为JSON或TXT文件

#### 2.5.3 交互要求
- 点击“静态分析” → 自动扫描合约，输出问题列表
- 点击“导出日志” → 下载当前运行记录
- 支持“复制结果”按钮，方便粘贴至报告或分享

## 三、非功能性需求

### 3.1 性能要求
- 页面加载时间 ≤ 3秒
- 编译合约响应时间 ≤ 5秒（简单合约）
- 调试操作延迟 ≤ 1秒

### 3.2 兼容性要求
- 支持主流浏览器：Chrome、Firefox、Edge（最新版）
- 支持响应式设计，适配平板与桌面端

### 3.3 安全性要求
- 所有合约执行在沙箱环境中，不影响真实链上资产
- 用户代码仅在当前会话有效，不持久化至服务器（除非主动保存）
- 支持会话超时自动清理环境

### 3.4 可用性要求
- 界面简洁直观，符合开发者习惯
- 提供新手引导（如：“First Time? Start Here!”）
- 支持快捷键操作（Ctrl+S, F5, F9等）
- 提供帮助文档与示例项目

## 四、界面参考与样式说明

- **主题色**：深蓝/深灰背景 + 浅色文字 + 高亮蓝/绿色按钮
- **字体**：等宽字体（如 Fira Code、Monaco）用于代码编辑器
- **图标**：使用SVG图标，保持一致性（如文件、编译、调试、部署）
- **布局**：三栏式（左文件、中编辑、右调试），顶部工具栏
- **参考界面**：Remix IDE（https://remix.ethereum.org）布局与交互风格
