什么是物联网？
14:30
🤖

物联网（Internet of Things，IoT）是指通过信息传感设备，按约定的协议，将任何物体与网络相连接，物体通过信息传播媒介进行信息交换和通信，以实现智能化识别、定位、跟踪、监控和管理的一种网络。

物联网的三层架构：

  • 感知层：负责信息采集和物体识别（传感器、RFID、摄像头等）
  • 网络层：负责信息传输和处理（互联网、移动网络、WiFi等）
  • 应用层：负责行业应用和信息服务（智能家居、智慧城市、工业监控等）

典型应用场景：

  • 智能家居：智能灯光、智能门锁、智能家电
  • 智慧城市：智能交通、环境监测、公共安全
  • 工业物联网：设备监控、生产优化、预测维护
  • 智慧医疗：远程监护、医疗设备管理

MQTT协议的工作原理是什么？
14:35
🤖

MQTT（Message Queuing Telemetry Transport）是一种轻量级的发布/订阅消息传输协议，专为物联网设备设计。

工作原理：

  1. Broker（代理服务器）：负责接收和分发消息
  2. Publisher（发布者）：设备向特定主题发布消息
  3. Subscriber（订阅者）：设备订阅特定主题接收消息
Python MQTT示例代码 
import paho.mqtt.client as mqtt

# 连接到MQTT Broker
client = mqtt.Client()
client.connect("broker.hivemq.com", 1883, 60)

# 发布消息
client.publish("sensor/temperature", "25.5°C")

# 订阅主题
client.subscribe("sensor/temperature")

MQTT特点：

  • 轻量级：协议头部最小仅2字节
  • 可靠传输：支持QoS质量等级（0、1、2）
  • 低功耗：适合资源受限的设备
  • 实时性：支持实时消息推送
